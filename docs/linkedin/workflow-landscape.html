1

Submit a repo

Paste a public GitHub link, optional assignment brief, pick roast level and language

2

Validate request

FastAPI checks the URL and daily quota, returns 202 and queues the roast

3

Fetch from GitHub

Repo metadata, commit SHA and tarball. Public repos only, no GitHub login

4

Filter and mask

Skip junk and binaries, cap 150 files / 200 KB, mask API keys as ***MASKED***

5

AI review

GPT-5.5 with Structured Outputs. Scores first as a neutral reviewer, then writes in the chosen tone

6

Validate output

Pydantic checks scores, real file paths and list sizes. One retry on bad output

7

Save

PostgreSQL stores the roast, mode, model used and token counts for the admin panel

8

Report

Score ring, 6 categories, roast, fixes by priority. Download PDF or copy as checklist

Safety by design

  • Code is never run. Repos are read as plain text only
  • Secrets masked before anything reaches the AI
  • Prompt injection ignored: repo content is marked untrusted data
  • Roasts the code, never the person. No profanity, PG and kind

Built with

  • Backend: FastAPI, SQLAlchemy, Alembic, PostgreSQL
  • Frontend: React, TypeScript, Vite, Chakra UI
  • AI: OpenAI Structured Outputs + Pydantic validation
  • Ops: Docker Compose on a VPS, Traefik HTTPS, GitHub Actions CI
